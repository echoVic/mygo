# 从前端调用 Go

前端通过**绑定服务**（bound service）调用 Go：页面可以调用已绑定 Go 值的导出方法，方法也可以通过**通道**（channel）流式返回数据。Go 还可以通过**带类型的事件**（typed event）向页面发送数据。`mygo generate` 为这些接口生成 TypeScript 客户端，让调用、通道和事件在两端都接受编译器的类型检查，并在编辑器中提供文档提示。

这是网页调用 Go 的方式。[原生 UI](ui/README.md) 本身就是 Go：它的视图直接调用你的代码，不需要这一套。

## 绑定服务

在 `App.Run` 之前把一个值传给 `mygo.Bind`：

```go
// Notes stores the user's notes.
type Notes struct {
	mu    sync.Mutex
	items []Note
}

// Note is a note.
type Note struct {
	ID    int64  `json:"id"`
	Title string `json:"title"`
	Body  string `json:"body,omitempty"`
}

// Add creates a note and returns it.
func (n *Notes) Add(title string) (Note, error) {
	if title == "" {
		return Note{}, errors.New("a note needs a title")
	}
	n.mu.Lock()
	defer n.mu.Unlock()
	note := Note{ID: int64(len(n.items) + 1), Title: title}
	n.items = append(n.items, note)
	return note, nil
}

// List returns all notes.
func (n *Notes) List() []Note {
	n.mu.Lock()
	defer n.mu.Unlock()
	return slices.Clone(n.items)
}

func main() {
	mygo.Bind(&Notes{})
	// ...
}
```

服务以其类型命名，即 `Notes`，该值的每个导出方法都可调用，这里就是 `Notes.add(title)` 和 `Notes.list()`。`mygo.BindAs("Store", v)` 可以显式命名，用于名称冲突的类型。名称被重复占用，或某个方法使用了 JSON 无法编码的类型（例如通道或函数）时，`Bind` 会 panic，让错误在启动时就暴露。

方法可以：

- 接受任意数量可用 JSON 编码的参数，也支持可变参数；如果有 `context.Context`，则放在它之后；
- 接受 `*mygo.Channel[T]` 参数，在方法运行期间把值流式发给调用方（见[通道](#通道)）；
- 不返回值、返回一个值、一个 error，或一个值和一个 error。

每次调用都在独立的 goroutine 中运行，因此方法可以阻塞，例如等待对话框或网络请求。多个方法也可以并发运行，需要像上例一样用互斥锁保护共享状态。方法中的 panic 会被捕获并记录，再像 error 一样报告给调用方。

### context 与调用窗口

第一个参数是 `context.Context` 的方法会得到一个上下文，在发起调用的页面导航离开或窗口关闭时被取消：把它传给耗时的工作。`mygo.CallerWindow(ctx)` 返回发起调用的窗口，例如让对话框依附于它，`mygo.CallerPage(ctx)` 返回页面，用来区分原生 UI 窗口中各个 Web 视图的页面（[Web 视图](ui/web-view.md)）：

```go
// Export asks where to save the notes and writes them there. It returns the
// chosen path, or "" when the user canceled.
func (n *Notes) Export(ctx context.Context) (string, error) {
	path, err := mygo.Dialog.Save(mygo.SaveDialogOptions{
		Parent:      mygo.CallerWindow(ctx), // a sheet of that window on macOS
		DefaultPath: "notes.json",
	})
	if err != nil || path == "" {
		return "", err
	}
	// ...
	return path, nil
}
```

在 TypeScript 一侧，上下文不是参数：`Notes.export(): Promise<string>`。

## 生成的客户端

`mygo generate` 把客户端写到 mygo.config.ts 中 `bindings` 指定的路径，新项目中是 `src/mygo.ts`。Go 代码变化时，`mygo dev` 会重新生成客户端；`mygo build` 也会在构建前端之前重新生成，因此通常不必手动运行生成命令。如果应用既不绑定服务，也不声明事件，就不会写出任何客户端文件，即使项目中有 package.json（例如原生 UI 应用附带的网站）。上面的服务会生成：

```ts
// Code generated by `mygo generate`. DO NOT EDIT.

import { call, event } from "mygo-runtime";

/** Note is a note. */
export interface Note {
  id: number;
  title: string;
  body?: string;
}

/** Notes stores the user's notes. */
export const Notes = {
  /** Add creates a note and returns it. */
  add(title: string): Promise<Note> {
    return call("Notes.Add", title);
  },
  /** List returns all notes. */
  list(): Promise<Note[]> {
    return call("Notes.List");
  },
  // ...
} as const;
```

方法名变成小驼峰（`GetUserByID` → `getUserByID`，`URLFor` → `urlFor`），参数保留 Go 中的名字，Go 文档注释变成 TSDoc。客户端导入 `mygo-runtime`，前端依赖它。如果同一个服务的两个方法或两个事件映射到同一个客户端属性名，生成就会失败。错误会指出两处声明，让你可以重命名其中一个，而不会悄悄掩盖另一个。

生成客户端时，mygo generate 会构建应用，并在设置了 `MYGO_GENERATE` 的情况下运行它：`App.Run` 这时写出客户端并返回，不打开窗口。因此 `main` 会一直运行到 `App.Run`；把不能在那时执行的工作，例如迁移数据库，放到应用就绪之后，即 `App.WhenReady` 中。

### 类型

值以 JSON 的形式在 Go 和 JavaScript 之间传递，遵循 Go 的 `encoding/json/v2` 规则，客户端声明对应的类型：

| Go | TypeScript |
|---|---|
| `bool` | `boolean` |
| `string` | `string` |
| `int`, `uint8`, `float64` 及其他数字 | `number` |
| `[]byte` | `string`，base64 编码 |
| `time.Time` | `string`，RFC 3339 |
| `time.Duration` | `number`，以纳秒为单位 |
| `[]T`, `[N]T` | `T[]`；nil 切片到达时为 `[]` |
| `map[string]T` | `Record<string, T>`；数字键为 `Record<number, T>` |
| 结构体 | 同名的 interface |
| `*T` | `T \| null` |
| `any` 及其他 interface | `unknown` |
| 带常量的命名 string 或 number 类型 | 其值的联合类型 |
| 带 `MarshalJSON` 方法的类型 | `unknown` |
| 带 `MarshalText` 方法的类型 | `string` |

结构体字段按 `json` 标签命名，没有标签的字段保留 Go 名称，例如 `Title`：请给字段加上 `json:"title"` 这样的标签。标有 `omitempty` 或 `omitzero` 的字段是可选的（`body?: string`），`-` 则省略字段。JavaScript 数字在 2⁵³ 以内是精确的，所以要用 `string` 选项把更大的 ID 编码为字符串，即 `json:"id,string"`，在 TypeScript 中它们就成了 `string`。

嵌入的 `map[string]T` 或 `jsontext.Value`（`json:",embed"`）会添加顶层成员，而不是成为嵌套字段。它生成的对象允许用 `[key: string]: unknown` 添加额外的键，而已声明的字段保留各自的类型。

带常量的命名 string 类型变成联合类型：

```go
// Filter selects which notes are listed.
type Filter string

const (
	FilterAll  Filter = "all"
	FilterDone Filter = "done"
)
```

```ts
/** Filter selects which notes are listed. */
export type Filter = "all" | "done";
```

### 错误

方法返回非 nil error 时，promise 会以 `CallError` 进入拒绝状态，错误消息就是该 error 的文本：

```ts
import { isCallError } from "mygo-runtime";

try {
  await Notes.add("");
} catch (err) {
  if (isCallError(err)) showError(err.message); // "a note needs a title"
  else throw err;
}
```

`err.method` 是失败方法的名称，即 `"Notes.Add"`。

## 事件

事件把值从 Go 送到页面。在包级别用其载荷类型声明事件，这样 `mygo generate` 能找到它们：

```go
// Progress is sent while an export runs.
var Progress = mygo.NewEvent[ExportProgress]("progress")

// ExportProgress is how far an export got.
type ExportProgress struct {
	Done  int `json:"done"`
	Total int `json:"total"`
}
```

`Emit` 把事件发给一个窗口的页面，`Broadcast` 发给每个窗口：

```go
Progress.Emit(win, ExportProgress{Done: 3, Total: 10})
Progress.Broadcast(ExportProgress{Done: 10, Total: 10})
```

在页面 DOM 就绪之前发出的事件，会在就绪后送达。窗口关闭后 `Emit` 返回 error，借此可以结束向窗口发送数据的循环：

```go
go func() {
	for t := range time.Tick(time.Second) {
		if Tick.Emit(win, t) != nil {
			return // the window was closed
		}
	}
}()
```

客户端在 `events` 下列出事件，以驼峰命名（`"progress"` → `events.progress`，`"notes:changed"` → `events.notesChanged`）：

```ts
import { events } from "./mygo";

const off = events.progress.on(({ done, total }) => {
  bar.value = done / total;
});
// later
off();

events.progress.once((p) => console.log("first progress", p));
```

事件名称必须唯一；以 `mygo:` 开头的名称是保留的。

## 通道

会随时间产生值的方法，例如命令打印的行、模型回答的词元或下载的进度，通过 `*mygo.Channel[T]` 参数把这些值流式发给调用方，就像分块到达的响应：

```go
// Tail runs a command and sends the lines it prints.
func (Shell) Tail(ctx context.Context, command string, lines *mygo.Channel[string]) error {
	cmd := exec.CommandContext(ctx, "sh", "-c", command)
	out, err := cmd.StdoutPipe()
	if err != nil {
		return err
	}
	if err := cmd.Start(); err != nil {
		return err
	}
	scanner := bufio.NewScanner(out)
	for scanner.Scan() {
		if err := lines.Send(scanner.Text()); err != nil {
			return err // the page stopped listening
		}
	}
	return cmd.Wait()
}
```

客户端把这个参数的类型定为 `mygo-runtime` 的 `Channel`，由页面创建它并在该位置传入，然后迭代通道：

```ts
import { Channel } from "mygo-runtime";
import { Shell } from "./mygo";

const lines = new Channel<string>();
const done = Shell.tail("ping -c 3 example.com", lines);
for await (const line of lines) output.append(line + "\n");
await done; // rejects if Tail returned an error
```

除了迭代，也可以传一个函数，`new Channel<string>((line) => output.append(line))`，或设置 `lines.onmessage`。

- 数据按顺序送达，且所有数据都会在本次调用的 promise 完成或失败之前送达。
- 方法返回或调用 `Close` 时通道关闭：循环取完之前已发送的值后结束，并调用 `onclose`。
- 页面调用 `lines.close()` 或跳出循环即可停止接收：之后 `Send` 会返回 `mygo.ErrChannelClosed`，方法的上下文也会被取消，本例中的命令会因此终止。页面导航离开或窗口关闭时也一样。
- 页面尚未读取的数据超过一 MiB 时，`Send` 会等待，避免方法产生数据的速度超过页面读取速度，导致数据在内存中堆积。在主线程上调用时（例如在事件监听器中），则不会等待。

一个通道只服务一次调用。通道只能作为参数：`Bind` 拒绝返回通道或在另一个值里接受通道的方法。

如何选择事件和通道？事件会发送给页面的所有监听器，页面存在期间都可以接收；通道只传递一次调用的结果，并随调用结束而关闭。

## 不用生成的客户端

`mygo-runtime` 按名称调用方法、订阅事件，没有构建步骤的页面可以在 `window.mygo` 上访问同样的函数：

```ts
import { call, on } from "mygo-runtime";

const note = await call<Note>("Notes.Add", "Groceries");
on<ExportProgress>("progress", (p) => console.log(p));
```

```html
<script>
  mygo.call("Notes.Add", "Groceries").then((note) => console.log(note));
  // mygo.channel() creates a channel.
  const lines = mygo.channel((line) => console.log(line));
  mygo.call("Shell.Tail", "ls", lines);
</script>
```

未传入的参数在 Go 中取零值。

## 谁能调用

只有应用自己的页面可以调用 Go 方法：它的前端页面和自定义协议的页面（见[前端](frontend.md)）、`file:` 和 `about:` 页面，以及在开发构建中由 localhost 提供的页面，例如开发服务器。显示其他站点的窗口，例如 `https://example.com`，会阻止它们调用 Go，除非 `PageOptions.TrustedOrigins` 列出了它们的来源：

```go
mygo.NewWindow(mygo.WindowOptions{
	URL:  "https://app.example.com",
	Page: mygo.PageOptions{TrustedOrigins: []string{"https://app.example.com"}},
})
```

`"*"` 信任每个来源，包括页面导航到的任何站点：在显示你无法控制的内容的窗口中避免使用它。页面中嵌入的 iframe 永远不能调用 Go，无论其来源是什么；只有窗口的顶层页面可以。

受信任的页面还能做什么，以及如何显示不属于应用的内容：见[信任](frontend.md#信任)。

## 从 Go 到页面

事件是让页面得知变化的方式。要在页面中运行代码，通常是为了自动化或测试它，请使用 `Page.Eval`，它返回表达式的值，会等待 promise，并按 JSON 解码，也可以用 `mygo.EvalAs[T]` 把它解码为 Go 类型：

```go
title, err := mygo.EvalAs[string](win.Page(), "document.title")
count, err := mygo.EvalAs[int](win.Page(), "const items = document.querySelectorAll('li'); return items.length")
```

语句会作为异步函数的函数体运行，所以 `return` 产生值。抛出异常的脚本会返回 `*mygo.EvalError`。脚本仍在等待时，如果页面导航离开（加载、重新加载、更改 location）或窗口关闭，会返回错误；`history.pushState` 和新的片段（fragment）仍留在页面中。
