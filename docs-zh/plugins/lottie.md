# Lottie

纯 Go 的 `plugins/lottie` 包在原生 UI 中播放 Lottie JSON 的一个限定子集。它通过 MyGo 公开的绘制器（painter）渲染矢量形状，不需要 JavaScript 运行时、npm 包或原生库，也不需要用 `mygo.Use` 注册。

## 加载和绘制

只加载一次，每个视图保留一个播放器，在元素的绘制回调中绘制它。播放器会自动开始播放。边界以 DIP 为单位；合成保持宽高比放入边界并居中，绘制的内容不会超出它自己的矩形，与其他 Lottie 播放器一致。路径按绘制时的尺寸光栅化，所以小尺寸的合成放大绘制后依然清晰。

```go
import (
    _ "embed"

    "github.com/egoist/mygo/plugins/lottie"
    "github.com/egoist/mygo/ui"
)

//go:embed success.json
var data []byte

// During initialization; handle the error before showing the view:
animation, err := lottie.Load(data)
if err != nil {
    return err
}
player := animation.NewPlayer(lottie.PlayerOptions{Loop: true, Speed: 1})

// Inside the view, using that same player:
ui.Box(c).Size(200, 200).Label("Saved").Draw(player.Draw)
```

`Load` 解码出的数据归它所有。一个动画可以由多个播放器共享，每个播放器有自己的时钟。`Width`、`Height`、`FrameRate` 和 `Duration()` 描述合成，修改这些导出的元数据不会改变播放。播放器的方法可以并发调用；只在一个视图的绘制回调中使用 `Draw`，不要保留它的绘制器。零值播放器什么都不绘制。

## 播放

`NewPlayer()` 只播放一次，`NewPlayer(lottie.PlayerOptions{Loop: true})` 循环播放。`Speed` 是一个正的倍数；零、负数和非有限值按 1 处理。`Duration()` 返回合成时间，与速度无关。

| 方法 | 行为 |
| --- | --- |
| `Play()` | 从当前位置继续播放。单次动画播放到结尾后，要先重置或跳转，才能再次播放。 |
| `Pause()` | 停在最后绘制的位置。 |
| `Seek(time.Duration)` | 选择一个合成时间，限制在零到时长之间。保持播放或暂停状态。 |
| `Reset()` | 跳转到零，保持播放或暂停状态。 |
| `Draw(*ui.Painter, ui.Rect)` | 绘制当前帧，播放进行中时请求下一次绘制。 |

改变暂停或已播完的播放器后，要请求更新视图，让它的绘制回调再次运行。例如在按钮的处理器中：

```go
if ui.Button(c.Key("replay"), "Replay").Clicked() {
    player.Reset()
    player.Play()
    c.Services().Invalidate()
}
```

时钟来自 `Painter.Now()`，不会启动定时器或 goroutine。暂停和跳转会在下一次绘制时重新确定时钟的起点，所以暂停的时间不会推进动画。单次播放的播放器停在最后一帧，不再请求帧。开启减少动效时，播放器不会推进，也不请求动画帧：它显示第一帧，或 `Seek`、`Reset` 选择的那一帧。为有意义的动画提供辅助功能标签，并把关键状态也用文本表达出来。

## 支持的 JSON

第一个版本面向简单的形状素材，从任意 After Effects 项目导出并不能保证兼容。对于能识别、会改变渲染但不在子集内的功能，`Load` 会报错，并附上图层、组或属性的上下文。

| 范围 | 支持的内容 |
| --- | --- |
| 合成 | 宽和高为正整数（`100` 或 `100.0`；`100.5` 会被拒绝），正的帧率，入点和出点。 |
| 图层 | 2D 形状图层（`ty: 4`）、纯色图层（`ty: 1`）、预合成图层（`ty: 0`）和空图层（`ty: 3`）。图层从入点开始显示，显示到出点之前，出点那一帧不显示，与 lottie-web 一致（lottie-ios 在出点也显示）。空图层和隐藏的图层（`hd: true`）什么都不绘制，只作为父级起作用。图层的开始时间（`st`）和时间伸缩（`sr`）只改变预合成显示的内容：每个图层的关键帧以及入点和出点都以它所在合成的帧计，lottie-web 和 lottie-ios 也这样读取，所以它们在其他图层上不起作用。 |
| 纯色图层 | 一个从 (0, 0) 到纯色尺寸（`sw`、`sh`）的矩形，用它的颜色（`sc`：导出工具写的 `#rrggbb`，或 `#rgb`）填充，受图层的变换和不透明度影响。尺寸必须给出且不能为负；尺寸为零的纯色什么都不绘制。其他 CSS 颜色和带透明度的十六进制颜色会被拒绝。 |
| 父子关系 | `parent` 为另一个图层 `ind` 的图层随它移动：它的变换在父级的变换之内，父级的变换又在父级的父级之内，依此类推，全部在同一帧采样。只有图层自己的入点和出点、可见性和不透明度决定它是否显示以及如何显示，父级的这些属性不起作用，与 After Effects 和 lottie-web 一致。父级不改变绘制顺序，绘制顺序仍是图层的顺序。`parent` 指向不存在的图层时视为没有父级，与 lottie-web 和 lottie-ios 一致。链接只在一个合成之内：预合成图层可以有父级，也可以作为周围图层的父级，它内部的图层只在彼此之间链接。 |
| 预合成 | 预合成图层（`ty: 0`）显示 `id` 等于其 `refId` 的资源，即带 `layers` 的资源：一个独立的合成，有自己的顺序、父子链接、入点和出点，以及嵌套的预合成，最多嵌套 16 层。它的帧是外层的帧减去图层的开始时间 `st`，再除以时间伸缩 `sr`（缺少时为 1；0 会被拒绝），与 lottie-web 的 `CompElement` 一致；伸缩为负时倒放。有时间重映射（`tm`）时，它的帧改为重映射的值（以秒计）乘以根合成的帧率（资源自己的 `fr` 会被忽略），此时 `st` 和 `sr` 不起作用；这个帧正好是图层的出点时取前一帧，与 lottie-web 一致，这样重映射到结尾时显示的是最后一帧。重映射的关键帧和图层变换的关键帧一样，以外层的帧计。内部的内容由图层的变换及其父级的变换放置，并裁剪到图层的矩形，即从 (0, 0) 到它的 `w` 和 `h`；这两个值必须给出，lottie-ios 也这样要求（缺少它们时，lottie-web 会把内容全部裁掉）。变换保持矩形时裁剪到矩形，旋转时裁剪到矩形变换后的四边形，在另一个预合成内部时裁剪到两者的交集。面积为零的矩形什么都不显示。图层的不透明度会乘到内部的每个形状上（见下文）。显示同一资源的所有图层共享对它的同一次读取，其静态轮廓只构建一次。包含自身的资源（无论是否经由其他资源）、没有资源或有多个资源使用的 id，以及没有图层的资源（例如图片，`p`、`u`），在有绘制内容的图层显示它们时都是错误；没有这类图层显示的资源不会被读取，无论它们是什么。隐藏的、透明的预合成，或者处于其入点和出点之外的预合成，不会对内部采样。 |
| 几何 | 三次贝塞尔路径、圆角矩形、椭圆；使用非零或奇偶填充规则的复合路径。路径按顶点的顺序走向，与它的 `d`（0 到 3）无关，lottie-web 和 lottie-ios 也忽略 `d`。矩形或椭圆顺时针（`d: 1` 或 `d: 2`）或逆时针（`d: 3`）走向；没有 `d` 时顺时针，与 lottie-ios 一致（lottie-web 让这样的矩形逆时针走向）。矩形从右上角开始，位于角的圆弧下方，沿右边向下；椭圆从顶部开始，与 lottie-web 和 lottie-ios 一致，这决定了修剪从哪里开始。宽或高为负时形状被镜像，走向随之反转；矩形的圆角最多为较短边的一半。 |
| 样式 | 纯色填充和描边，带不透明度、宽度、端点、连接和斜接限制（缺少 `ml` 时为 4）。样式绘制它所在组中列在它之前的所有几何，包括嵌套组中的几何，并应用它们的变换，与 lottie-web 一致：几何和样式可以按任意顺序排列，多个样式可以绘制同一几何，同一形状或组最多 16 个。列在最前的项在最上层，样式和嵌套组都是如此。描边的宽度以它自己所在组的坐标计：嵌套组的变换只移动它们几何的点，它们的不透明度只作用于它们自己的样式。组最多嵌套 32 层。隐藏的项会被跳过，无论它们是什么，与 lottie-ios 一致（lottie-web 仍会应用隐藏的修剪）。 |
| 修剪路径 | 修剪（`tm`）带有起点 `s`、终点 `e` 和偏移 `o`，可以是静态值或关键帧，它裁切所在组中列在它之前的几何，包括嵌套组中的几何，与 lottie-web 的修剪修改器一致。绘制这些几何的每个样式都绘制剩下的部分，列在修剪之前的样式也是如此；填充把每一段当作闭合路径来填充。起点和终点是长度的百分比，限制在 0 到 100；偏移以度为单位，360 为整个长度，被偏移推过终点的切口绕回起点，在闭合路径的起点处连成一段。起点在终点之后时，按两者交换后裁切；起点等于终点时什么都不剩；0 到 100 且没有偏移时几何保持原样，闭合路径仍然闭合。同时修剪（`m: 1`）时，每个形状单独裁切，其子路径首尾相接；单独修剪（`m: 2`）时，所有形状按列出的顺序首尾相接，作为一个整体裁切。多个修剪按列出的顺序依次裁切，同一形状最多 8 个。长度沿曲线测量，在每个形状自己的坐标中、应用任何组的变换之前测量，与 lottie-web 一致。值为静态且几何不变的修剪由 `Load` 裁切一次，其他修剪每帧裁切。 |
| 变换 | 图层和嵌套组上的锚点、位置、缩放、旋转和不透明度。拆分为 `x` 和 `y` 的位置（`p.s: true`）各自独立动画；它的 `z` 会被忽略，与任何 2D 值的第三个分量一样。接受静态为零的倾斜字段。 |
| 属性 | 静态和关键帧的标量、2D 点、颜色和路径值；定格、线性和三次时间贝塞尔缓动，包括回拉（back）和过冲缓动（`y` 控制点在 0 到 1 之外；`x` 控制点限制在 0 到 1）。路径变形保持顶点数和闭合或开放状态。属性是否为关键帧由它的值决定，与 lottie-web 一致：`k` 是对象列表时为关键帧。它的 `a` 标志会被忽略，导出工具写的这个标志并不总是与实际相符。 |
| 分量缓动 | 写成数组的控制点（`"o": {"x": [0.2, 0.6], "y": [0, 0]}`）让每个分量沿各自的曲线缓动：点的 `x` 和 `y`，颜色的各个通道。第 n 个分量使用每个控制点的第 n 项，控制点的项数不够时使用第 0 项，与 lottie-web 一致；超出值的分量数的项会被忽略，例如导出为 `[100, 100, 100]` 的缩放的第三项。标量使用第一项。路径只有一条曲线：它的关键帧的控制点各项必须一致。 |
| 空间切线 | 带有出切线 `to` 和入切线 `ti` 的 2D 点关键帧（导出工具为位置和锚点写入它们：图层的、组的、矩形的、椭圆的）沿三次贝塞尔曲线运动：从它的值出发，经过值 + `to` 和下一个值 + `ti`，到达下一个值。缓动后的进度是曲线长度的比例，长度由 `Load` 测量一次，所以运动沿曲线保持匀速；它准确地从关键帧的值开始，在关键帧的值结束。过冲的缓动越过曲线的哪一端，值就停在哪一端。没有切线或切线为零时，值沿直线运动。 |

`Load` 作为值读取的每个数字都必须在 ±10,000,000（1e7）之内：合成的尺寸、帧率以及入点和出点，图层的入点和出点、`ind` 和 `parent`，纯色的尺寸，以及每个坐标、尺寸、缩放、角度、颜色、不透明度、宽度、斜接限制，修剪的起点、终点和偏移，关键帧时间和缓动控制点。合成中有超出范围的数字时，`Load` 会拒绝它。过冲的缓动仍可能把值推到范围之外，一连串大的缩放也可能溢出；这时 `Draw` 会跳过无法绘制的内容，而不是失败。过冲的值仍然有效：不透明度和颜色通道限制在各自的范围内，修剪的起点和终点限制在 0 到 100，宽度降到零或以下的描边不绘制。

`Load` 作为整数读取的数字（图层的类型 `ty`、`ind`、`parent` 和 `ddd`，关键帧的定格 `h`，描边的端点和连接，填充规则，形状的方向，修剪的模式）可以写成浮点数，有些导出工具会把所有数字都写成浮点数：`4.0` 读作 4，`4.5` 是错误。

`Load` 只解析一次父子链接。`parent` 对应多个图层的 `ind`、链接形成环、祖先链超过 32 层，都是错误，错误信息会指明图层。空图层或隐藏的图层是有绘制内容的图层的祖先时，会读取它的变换，这个变换和其他变换一样必须在子集内（2D，没有倾斜、自动定向或表达式）；它携带的其他内容（蒙版、效果、轨道遮罩、混合模式、时间重映射、预合成的资源）只会改变它自己如何绘制，因此会被忽略。每个图层的 `ind` 都会被读取，用于解析链接；不放置任何有绘制内容的图层的空图层和隐藏图层，除此之外都会被跳过，无论它们包含什么。

`Load` 限制一帧的工作量，预合成的图层和形状按显示它的每个图层重复计数，嵌套时相乘：最多 10,000 个图层和 262,144（2^18）个形状项（几何、样式、修剪和组）。超出限制的文件是错误：一个文件在显示两次的资源中再显示另一个资源两次，依此类推，只需几 KB 就会绘制 2^n 个图层。lottie-ios 的 189 个示例文件中，嵌套最深的有 4 层，展开后最大的有 1,139 个图层。

一个组只能有一个变换（`tr`），有多个时会被拒绝。2D 点以外的值（旋转、颜色）上的空间切线会被拒绝；沿空间切线运动的关键帧只有一条曲线，所以其上的分量缓动也会被拒绝，与 lottie-web 一致。颜色在 JSON 的颜色空间中逐通道插值。

不支持的功能包括图片、文本、蒙版、轨道遮罩、混合模式、效果、表达式、3D、自动定向、预合成以外图层上的时间重映射、渐变、中继器以及其他形状操作。

描边随它的变换缩放，变换不均匀缩放时描边也不均匀，与 After Effects 一致。

不透明度乘到每个图元的 alpha 上，与 lottie-web 的 canvas 渲染器一致。因此，半透明组中相互重叠的子项、填充和描边，以及半透明预合成中的图层，看起来可能与 After Effects 的隔离合成不同：在 After Effects 只显示最上层的地方，它们会相互透出。这个版本不会分配离屏图层来隔离组或预合成的不透明度，也不声称完全符合 Lottie 规范。

## 示例和测试

运行 `go run ./examples/lottie`，可以看到一个原创的内嵌轨道徽章动画，带播放、暂停、重置和跳转控件：徽章上由修剪路径画出的对勾，两者都以一个脉动的空图层为父级；两个点沿空间切线绕轨道运动，它们来自同一个预合成，显示了两次，第二次经过时间伸缩。示例文件采用本仓库的许可证，不含第三方素材。

`go test ./plugins/lottie` 使用确定性的 `ui.Tester` 渲染和时钟推进来检查像素、时间、控件、减少动效和校验。原生窗口的行为和 GPU 输出需要在桌面上运行才能验证。

要测量子集能播放一批真实文件中的多少，把 `LOTTIE_CORPUS` 指向存放它们的目录：

```sh
LOTTIE_CORPUS=path/to/samples go test -v -run Corpus ./plugins/lottie
```

测试会加载其中的每个 Lottie 文档（带 `layers` 的 JSON 对象），在每个能加载的文件中抽取多帧绘制，有任何 panic 就失败。它会记录能加载的比例，包括总体和每个顶层文件夹的比例，以及每个无法加载的文件的第一个错误，相同的错误归为一组，最常见的排在前面。没有设置这个变量时跳过。
